# OrderFlow

Учебный backend-проект на Go для работы с заказами: создание, расчёт стоимости, хранение и подтверждение. Проект постепенно развивается до взаимодействия с сервисом склада и обработки событий.

Технологии: Go, PostgreSQL, Redis, Docker Compose. Далее — gRPC, Kafka и Kubernetes.

## Этапы

- [x] Доменная модель заказа и HTTP API.
- [x] PostgreSQL: миграции и транзакционное сохранение.
- [x] Dockerfile и запуск через Docker Compose.
- [x] Redis: кеширование заказов и сброс кеша при изменении статуса.
- [x] Подтверждение заказа.
- [x] Разделение приложения на запуск, HTTP, сервис и хранилища.
- [x] Тесты основных сценариев.
- [ ] **Текущий этап: gRPC-сервис склада** — контракт, генерация Go-кода, сервер и подключение к заказам.
- [ ] Проверка доступности товаров при подтверждении заказа.
- [ ] Kafka: события создания и подтверждения заказа.
- [ ] Outbox и идемпотентная обработка событий.
- [ ] Обработка ошибок, таймауты и корректное завершение приложения.
- [ ] Логи, метрики и трассировка.
- [ ] Развёртывание в Kubernetes.
